# Golf 5 1.9 TDI BLS — Android USB-OTG Flasher & Firmware Tool
**ЕБУ**: Bosch EDC16U34 (`03G906021QJ`, SW `391847` / `1037391847P447HAXN`)  
**Автомобіль**: Volkswagen Golf 5 (1K1), 1.9 TDI 105 к.с. (BLS, DPF OFF, EGR OFF)

Цей проект містить повний набір інструментів для прошивки блоку керування двигуном прямо зі смартфона Android через звичайний кабель **USB-OTG** та діагностичний адаптер **MPPS / KKL 409.1 (FTDI)**.

## ⚡ Що вдосконалено в прошивці `stage1_refined`?

1. **Hot Start Fix (Миттєвий запуск на гарячу)**:
   - В оновленій карті `StSys_trqStrtBas_MAP` (0x1F0762) піднято пусковий момент на 250 об/хв при температурі від 40°C до 100°C з 0.0 Нм до **108–125 Нм**. Стартер схоплює за пів оберту без тривалого крутіння.
2. **Плавність та підрив на 4–5 передачах (Mid-Range Punch)**:
   - Усунено провал у карті обмеження димності (`SMK-2500` на 0x1D6602, 2500 об/хв): подачу плавно піднято з 56.50 мг до **58.50 мг** (+15 Нм на трасі).
   - Збережено безпеку для двомасового маховика (DMF) на низьких обертах (<2200 об/хв).
3. **Eco Cruise SOI (+0.7° на трасі)**:
   - На 5–6 передачах при швидкостях 90–120 км/год (1750–2250 об/хв, 15–25 мг) кут випередження впорскування оптимізовано під заглушений EGR, що покращує спалювання палива та знижує витрату в круїзному режимі.
4. **100% збереження захистів турбіни та двигуна**:
   - Максимальний наддув: 2214 мбар (Garrett GT1646V / KKK BV39 у зеленій зоні надійності).
   - Активний захист за температурою вихлопу (EGT) та датчик CTSCD.
   - Повністю відключена регенерація DPF (0.0 мг пост-впорскування).

## 📱 Спосіб 1: Прошивка через додаток Android (APK)

### Необхідне обладнання:
1. Будь-який телефон або планшет на **Android 8.0+** з підтримкою **USB-OTG**.
2. **OTG перехідник** (Type-C -> USB-A або Micro-USB -> USB-A).
3. Кабель **MPPS v13 / v16 / v18** або **KKL 409.1 (чип FTDI FT232RL)**, вставлений в роз'єм OBD2 авто.

### Інструкція з прошивки:
1. Встановіть додаток `EDC16 Flasher` на телефон.
2. Увімкніть на телефоні режим **«У літаку»** (щоб випадковий дзвінок не перервав з'єднання).
3. Підключіть кабель до діагностичного роз'єму OBD2 автомобіля.
4. Підключіть USB до телефона через OTG-перехідник.
5. Увімкніть запалювання автомобіля (двигун НЕ запускати!). Вимкніть фари, магнітолу, кондиціонер.
6. На телефоні відкриється додаток і з'явиться запит: *«Дозволити додатку EDC16 Flasher доступ до USB-пристрою?»* -> натисніть **OK**.
7. Натисніть кнопку **«Зчитати дані ЕБУ»** — з'явиться серійний номер та версія софту (`03G906021QJ 391847`).
8. Натисніть кнопку **«Записати Stage 1 Refined»**.
9. Зачекайте заповнення шкали прогресу (орієнтовно 2–4 хвилини).
10. Після напису *«Прошивку успішно записано!»* вимкніть запалювання на 10 секунд.
11. Запустіть двигун та насолоджуйтесь ідеальною динамікою!

## 💻 Спосіб 2: Швидка прошивка через Termux (CLI)

Якщо вам зручно запустити прошивку з терміналу Termux на телефоні:

1. Встановіть додаток **Termux** (рекомендовано з F-Droid).
2. Скопіюйте папку `termux` на телефон або завантажте файли.
3. У терміналі Termux виконайте:
   ```bash
   cd termux
   chmod +x setup_termux.sh
   ./setup_termux.sh
   ```
4. Підключіть кабель через OTG і перевірте підключення:
   ```bash
   python edc16_flasher.py -l
   ```
5. Зчитайте дані ЕБУ:
   ```bash
   python edc16_flasher.py -p /dev/ttyUSB0 -i
   ```
6. Запишіть прошивку:
   ```bash
   python edc16_flasher.py -p /dev/ttyUSB0 -f 03G906021QJ_stage1_refined_dpf_egr_off.bin
   ```
